Ubuntu 20.04 LTS + JetPack 5.1.3 — Full Installation on Jetson AGX Orin
⚠ Complete ALL steps in order. The Jetson ships without Ubuntu — you must flash it from a host PC using NVIDIA SDK Manager.
STEP 1 — HARDWARE PREP
Install NVMe SSD & Connect Host PC
1. Install M.2 NVMe SSD (512 GB min, Samsung 980 Pro recommended)
2. Connect Jetson to Ubuntu 20.04/22.04 host PC via USB-C cable
3. Hold RECOVERY button → press POWER → release RECOVERY
4. Verify: lsusb | grep NVIDIA → should show NVIDIA Corp.
STEP 2 — INSTALL NVIDIA SDK MANAGER (on Host PC)
Flash Ubuntu 20.04 LTS onto the Jetson
# On your Ubuntu HOST PC (not the Jetson): wget https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2004/x86_64/cuda-keyring_1.0-1_all.deb sudo dpkg -i cuda-keyring_1.0-1_all.deb sudo apt-get update && sudo apt-get install -y sdkmanager # Launch SDK Manager and flash: sdkmanager --archivedversions # Select: Jetson AGX Orin → JetPack 5.1.3 → Ubuntu 20.04 LTS # Components: L4T · CUDA 11.4 · cuDNN 8.6 · TensorRT 8.5 · VPI 2.0 · OpenCV # Click FLASH → wait ~30 minutes
STEP 3 — VERIFY UBUNTU ON JETSON
Confirm Ubuntu 20.04 LTS + CUDA + TensorRT
# SSH into Jetson or use HDMI monitor + keyboard: cat /etc/os-release | grep PRETTY_NAME # → Ubuntu 20.04.6 LTS nvcc --version # → CUDA compilation tools, release 11.4 python3 -c "import tensorrt; print(tensorrt.__version__)" # → 8.5.x ls /dev/nvdla* # → /dev/nvdla0 /dev/nvdla1 (both NVDLA v2.0 accelerators) nvidia-smi # → Jetson AGX Orin · 64 GB · CUDA 11.4
STEP 4 — OS HARDENING (CIS Level 2)
Secure Ubuntu for Enterprise SA-ID Deployment
#!/bin/bash # said_harden.sh — run as root on Jetson apt-get update && apt-get upgrade -y apt-get install -y ufw fail2ban auditd apparmor \ libpam-pwquality unattended-upgrades rkhunter # Firewall ufw default deny incoming ufw default allow outgoing ufw allow 22/tcp # SSH — restrict to management VLAN ufw allow 443/tcp # HTTPS to DHA/SARB ufw allow 8443/tcp # SA-ID Enterprise API ufw enable # Harden SSH sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config sed -i 's/PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config echo 'MaxAuthTries 3' >> /etc/ssh/sshd_config systemctl restart sshd # Kernel hardening cat >> /etc/sysctl.d/99-said.conf << 'EOF' net.ipv4.ip_forward = 0 net.ipv4.conf.all.accept_redirects = 0 kernel.randomize_va_space = 2 fs.suid_dumpable = 0 kernel.dmesg_restrict = 1 EOF sysctl -p /etc/sysctl.d/99-said.conf # Disable unused services systemctl disable bluetooth cups avahi-daemon echo "[SA-ID] Ubuntu hardening complete ✓"
STEP 5 — DOCKER + NVIDIA CONTAINER RUNTIME
GPU Passthrough for SA-ID Microservices
# Install Docker CE (arm64) curl -fsSL https://download.docker.com/linux/ubuntu/gpg \ | gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg echo "deb [arch=arm64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \ https://download.docker.com/linux/ubuntu focal stable" \ | tee /etc/apt/sources.list.d/docker.list apt-get update && apt-get install -y docker-ce docker-compose-plugin # NVIDIA Container Toolkit (GPU → Docker passthrough) distribution=ubuntu20.04 curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | apt-key add - curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list \ | tee /etc/apt/sources.list.d/nvidia-docker.list apt-get update && apt-get install -y nvidia-container-toolkit # Set NVIDIA as default Docker runtime cat > /etc/docker/daemon.json << 'EOF' { "default-runtime": "nvidia", "runtimes": { "nvidia": { "path": "nvidia-container-runtime", "runtimeArgs": [] } } } EOF systemctl restart docker # Verify GPU inside Docker docker run --rm --gpus all nvcr.io/nvidia/l4t-base:r35.3.1 nvidia-smi # → Should show Jetson AGX Orin GPU
